For the [Hack the North](https://hackthenorth.com/) competition, 4 of us collaborated on a Chrome extension which aimed to improve the usage of GitHub readmes. 

As we struggled to navigate through the entire read me file, which sometimes is long and detailed, we decided to create a chrome extension which can create a navbar for quick navigation for the read me sections. 

This idea was before GitHub implemented their own version of read me parser.
