This project was the capstone project for my schooling. Specifically, we were required to create a chatbot which can answer the questions about the Brock University courses, and also about the [Canada Games 2022](https://www.canadagames.ca/previous-games/niagara-2022) which took place in Niagara.

This was the first time I was exposed to Docker, DevOps and backend in general, however, I found that it is something I absolutely enjoy when I started to build out the pipeline for hosting the application in Heroku. This application has now been taken down by Heroku due to lack of use. 

The more time I spent on this project, I learned how to actually make good software, I made a ton of mistakes, as this was my first time creating good quality software with a team. 
We learned how to scrape data from the different websites, and learned how to create scripts that can be used to clean up the data that is returned. This inturn was loaded into the SQLite database which stores data using flat files. 

This design was intentionally taken, as we didn't want to pay for the memory, as Heroku at that time didn't have free memory, at least not the amount we needed.

I did learn a lot of lessons, but one that I treasure is that, there are always things to learn and always things to experiment, just don't forget to have fun while at it.
